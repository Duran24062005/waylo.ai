# Fuentes de la imagen para compartir

`opengraph-image.tsx` dibuja la vista previa de los enlaces (WhatsApp, Facebook, LinkedIn, X) al compilar.
El generador de imágenes necesita archivos `.ttf`, así que estas fuentes viven aquí y no en `next/font`.

- `Pacifico-Regular.ttf` — Pacifico, el tipo del nombre "Waylo" en la app.
- `Poppins-Medium.ttf` — Poppins, el tipo de las etiquetas de la app.

Ambas son de Google Fonts y tienen licencia SIL Open Font License 1.1, que permite usarlas y redistribuirlas en un proyecto.
